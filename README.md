# Приложение для поиска вакансий

## Описание
Этот проект представляет собой интерфейс для работы с API сайта HeadHunter (hh.ru) для 
поиска и фильтрации вакансий по ключевым словам и уровню зарплаты.


# Установка

Клонируйте репозиторий:

``` git clone https://github.com/antondrevin/bank_project.git ```

**Установите зависимости, используя менеджер пакетов `poetry`:**
    
``` poetry install```

## Использование

Создайте новый проект и начните добавлять задачи.

Запустите скрипт: python main.py

Следуйте инструкциям на экране:

Введите поисковый запрос (например, "Python").

Укажите количество вакансий для вывода в топ N.

Введите ключевые слова для фильтрации вакансий (например, "разработка").

Введите желаемый уровень зарплаты (например, "100000").

## Пример структуры JSON-ответа, который будет записан в файл

## Описание классов и функций:

1. абстрактный класс VacancyAPI для работы с API сервиса с вакансиями
2. класс-наследник HeadHunterAPI подключается к API и получает вакансии.
3. Класс Vacancy имеет 4 атрибута и поддерживать методы сравнения вакансий между собой по зарплате,
   и валидирует данные, которыми инициализируются его атрибуты.
4. абстрактный класс BaseSaver и его наследник JSONSaver для сохранения информации о вакансиях в JSON-файл.
5. класс ConsoleInterface для взаимодействия с пользователем
6. main.py точка входа и объединяет весь функционал программы
